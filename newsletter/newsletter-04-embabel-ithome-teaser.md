## 一個為 JVM 而生的 Agent 框架

Embabel 是 Spring 之父 Rod Johnson 創立的開源 Agent 框架，
目標很直接：讓 Java / Kotlin 團隊不必砍掉重練、換語言、重寫系統，
就能在既有的 Spring 生態系裡寫出可維運的 AI Agent。

多數 Agent 框架的做法，是讓 LLM 一邊思考一邊決定下一步（ReAct 式的自主迴圈）。
Demo 很好看，但放進企業系統就會遇到老問題：
流程不可預測、無法解釋每一步為什麼發生、出錯時只能重試或人工介入。

Embabel 選了另一條路，它把三件事分開：

- **演算法管邏輯**：借用遊戲 AI 領域成熟的 GOAP（目標導向行動規劃），
  把工作拆成一個個 Action，用最短路徑演算法算出達成 Goal 的最佳路徑。
  決定「下一步做什麼」的是 100% 確定的演算法，不是模型的即興發揮。
- **LLM 管溝通**：摘要、判斷、草擬文案這些模型擅長的事交給模型；
  金額、次數、資格這些該精準的數字，仍由 Java 程式計算。
- **權重管偏好**：哪條路便宜、哪條路塞車，用成本調控。
  某個 API 掛掉時，成本瞬間飆高，規劃器會自動重新規劃改走別條路，
  不需要事先寫一堆 if-else 降級邏輯。

寫起來也很 Spring：用 `@Agent`、`@Action`、`@AchievesGoal` 這些註解描述流程，
搭配型別安全的領域物件，Agent 的每一步都能被測試、追蹤與驗收。

如果你是 Java 工程師，看到這裡應該會有一種熟悉感——
這正是當年 Spring 對企業開發做過的事：把不可控的東西，變成有紀律的工程。

## 但後端只是故事的一半

Agent 會思考、會規劃之後，下一個問題馬上出現：

**AI 產生的結果，前端要怎麼呈現？**

總不能讓 AI 直接產生任意的前端程式碼吧？

這就是系列後半段的主角：**json-render**。
<!--paywall-->
它讓 AI 不輸出程式碼，只輸出一份受限制的 UI 規格（JSON），
前端再用元件白名單把畫面安全地渲染出來。

這個系列我整理成了兩個可以直接使用的技能（skills），
解鎖後跟你完整介紹它們各自負責什麼、怎麼串成一個專案。

## 技能一：Embabel 後端 Agent 技能（Day 01–20）

系列前 20 天聚焦後端，這個技能涵蓋的核心能力包括：

- **GOAP 規劃**：把業務流程拆成 Action、用 Goal 描述成功狀態，
  由規劃器算出執行路徑，而不是讓 LLM 自由發揮。
- **世界狀態與條件**：不是每個 Action 在任何狀態都能執行，
  用前置條件把「什麼時候能做什麼」說清楚。
- **成本與排序**：靜態權重設定基本偏好（本地查詢便宜、遠端大模型昂貴），
  動態權重感知環境（API 塞車就繞道），行為偏好變成可調參數。
- **Blackboard 記憶**：Agent 的記憶不是一團字串，
  而是型別安全、可推導的物件狀態。
- **Replanning**：計畫趕不上變化時重新規劃，而不是硬寫降級流程。
- **工具分工與 Agentic RAG**：該 Java 算的交給工具，
  需要資料時讓 Agent 自己決定何時去搜尋文件。
- **可觀測與測試**：ActionAudit 讓每一步留下證據；
  測試測的是 prompt 組裝、工具暴露與 guardrail，而不是文案一字不差。

一句話總結：**讓 AI 有能力，但把能力放在可控邊界內。**

## 技能二：json-render 前端技能（Day 21–25）

後端會規劃之後，前端的挑戰是「安全地把 AI 的產出變成畫面」。
json-render / embabel-generative-ui 這個技能負責：

- **UI 規格而非程式碼**：AI 輸出的不是 JSX，
  而是一份 root + elements map 的 JSON spec，結構扁平、可驗證。
- **元件白名單（catalog）**：LLM 只能使用前端真的有實作的元件，
  「可用元件」和「可渲染元件」必須對得上，AI 就沒有機會夾帶奇怪的東西。
- **數字交給程式算**：圖表和表格的數據由後端計算填入，
  避免空表格、空圖，也避免模型悄悄竄改數字。
- **SSE 與漸進渲染**：規格用串流分段送達，
  前端能容錯處理「半截 JSON」，讓使用者看著畫面慢慢長出來，而不是空白等待。

## 最後五天：把兩個技能接成一個專案（Day 26–30）

系列的收尾，是把這兩個技能串起來：
使用者輸入一句自然語言需求，
後端 Embabel 規劃資料查詢與 dashboard spec，
前端一路顯示 Agent 的執行進度，漸進渲染出一個可互動、可驗收的 Dashboard。

從「AI 回答文字」走到「AI 長出畫面」，而且每一步都在邊界內。
