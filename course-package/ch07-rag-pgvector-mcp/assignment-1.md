# 章節 7 作業 1｜完成進階 AI 功能

## 單元定位

本章作業把四個單元的內容收攏成一次完整的實作驗收：RAG 知識庫、MCP 與 Skills 的理解、長期記憶三件套（非同步寫入、Metadata 隔離、雙路檢索），最後以「答題附來源、沒文件不硬答、新對話記得偏好」作為驗收底線。完成後，你的 AI CRM 助理就具備了第八章 Demo Day 展示所需的全部進階 AI 能力。

## 作業說明

依 u7 的實作任務清單完成以下項目：

**RAG 知識庫（單元 1、4）**

- u7-t1：整理 RAG 三步驟流程（Extract → Transform → Load）
- u7-t2：確認 pgvector 與 VectorStore 的分工
- u7-t3：記錄 1 個知識庫問答驗證情境

**MCP 與 Skills（單元 2）**

- u7-t4：理解 MCP Server / Client 在 Spring AI 的接入方式與呼叫流程
- u7-t5：理解 MCP 與 Skills 的角色差異與適用場景
- u7-t6：瀏覽 spring-ai-agent-utils 專案與工具清單，評估導入 SkillsTool 的版本前置條件

**長期記憶（單元 3）**

- u7-t7：設計非同步向量化儲存 Service 邏輯
- u7-t8：在 SSE 串流完成時（doOnComplete）觸發歷史寫入
- u7-t9：實作多路檢索與上下文合併邏輯

**驗收標準**

```text
請幫我驗證：主管能看到團隊每個業務的表現與 AI 診斷建議、業務能在工作台看到自己該跟進的客戶；上傳一份文件後問相關問題，AI 的回答確實有依照文件內容並標出參考來源；開一段新對話時，AI 還記得我之前提過的偏好。
```

## 口語稿

好，章節七的作業來了，題目是「完成進階 AI 功能」。這份作業是本章四個單元的總驗收，我把要做的事情分成三組，一組一組講清楚。

第一組是 RAG 知識庫，對應單元一和單元四。有三個任務：第一，整理 RAG 的三步驟流程——Extract、Transform、Load，我建議你不要只是抄名詞，而是用自己的話寫下每一步在你的專案裡對應到哪個類別、哪個方法：TextReader 讀檔、TokenTextSplitter 切塊、vectorStore.accept() 向量化入庫。第二，確認 pgvector 與 VectorStore 的分工——一句話講得出「誰在資料庫端、誰在程式端」才算過關。第三，記錄一個知識庫問答的驗證情境：上傳哪份文件、問了什麼問題、AI 引用了哪個來源，把這個情境完整記下來，第八章 Demo Day 你會直接用到它。

第二組是 MCP 與 Skills，對應單元二。這一組是理解型任務，不要求你把外部工具全部接起來。三件事：理解 MCP Server 和 Client 在 Spring AI 裡的接入方式與呼叫流程，你要能把「使用者提問到 AI 回答」的六個步驟講一遍；理解 MCP 與 Skills 的角色差異——記得那句口訣，MCP 擴充能力與資料，Skills 擴充知識與流程；最後，實際去瀏覽 spring-ai-agent-utils 這個專案，看看它的工具清單，並且評估導入 SkillsTool 的版本前置條件——它要求 Spring AI 2.0.0-RC1 以上，而我們專案用的是 M8，所以你要寫下的結論是：需不需要升版、升版影響哪些地方。這種「導入前先查前置條件」的習慣，比會寫程式更能保護你的專案。

第三組是長期記憶，對應單元三，這一組是純實作。三個任務環環相扣：先設計非同步向量化儲存的 Service 邏輯，也就是 ChatHistoryService，記得 metadata 要帶 sessionId、type 和時間；然後在 SSE 串流完成的時機點——doOnComplete——觸發歷史寫入，用 CompletableFuture.runAsync 丟背景執行，千萬不要做成同步寫入，那會讓每一次回覆都變慢，等於白做；最後實作多路檢索與上下文合併，文件一路取前三筆、該使用者的歷史一路取前兩筆，合併後交給模型。

驗收標準我直接用那份驗證提示詞，你把它交給 AI Agent 跑一遍，重點盯三件事：第一，上傳文件後提問，AI 的回答有依照文件內容、而且標出參考來源；第二，這條我特別強調——問一個知識庫裡沒有的問題，AI 要能承認找不到相關內容，不能硬答，很多同學會漏掉這個反向測試，但它才是企業級 AI 的分水嶺；第三，開一段全新的對話，AI 還記得你之前提過的偏好，證明長期記憶真的有寫進去、也真的檢索得出來。另外提示詞裡的主管團隊分析和業務工作台畫面，也一併確認能正常顯示。

交付的時候，除了程式碼，把你的驗證過程記錄下來——截圖或文字都可以，重點是「問了什麼、AI 答了什麼、引用了哪份來源」。做完這份作業，你的 AI CRM 助理就同時會查數字、讀文件、記得你，該有的進階能力都到位了。下一章，我們進入結訓專案衝刺——把整套系統做端到端的整合測試，然後準備 Demo Day，把它變成一個能放進履歷的完整作品。
