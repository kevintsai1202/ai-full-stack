## 使用規則

- `source-registry.md` 的每一筆來源都要保留原始 URL、文件名稱、版本或更新日期與本課使用位置。
- `issueflow-project-assignment.md` 是四章共用作業規格；各章的 task ID 不可任意改名，需依序交接產物。
- 安全標準與 npm／Playwright 執行結果是時間敏感資料；課堂報告要另外記錄實際執行日期。
- `lab/artifacts/` 是執行輸出，不是教材來源；若要交作業，學員需附命令、版本與輸出摘要。
