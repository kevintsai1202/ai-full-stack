# 自訂名單來源

## 目的

管理員會持續收到不同課程、活動或合作夥伴的 Excel 名單，因此名單來源不能只固定為
「問卷填寫／線上測驗／Dify 學員」。後台需允許管理員自行新增來源，並在重新登入、
更換裝置或重新部署後繼續使用。

## 操作流程

1. 進入 Admin 的「讀者管理」。
2. 在「名單來源」旁選擇「新增來源」。
3. 輸入顯示名稱，例如「2026 夏季班」，選擇「儲存並選用」。
4. 上傳 XLSX、預覽並確認匯入。
5. 到「電子報寄送」的邀請信區塊選擇同一來源，寄出訂閱確認信。

## 設計約束

- 系統預設來源鍵 `survey_form`、`exam`、`dify` 保持不變，避免歷史資料失聯。
- 自訂來源以 JSON 保存於既有 `app_setting` 的 `audience.sources`，不新增 migration。
- 顯示名稱與內部鍵分離；管理員只需理解顯示名稱。
- 同名來源不分大小寫視為同一項，不重複建立。
- 第一版只允許新增，不提供刪除或改名，避免歷史匯入資料與邀請紀錄失去對應。
- 自訂來源會同步出現在匯入、邀請信與原始資料來源篩選三個位置。
