## 旁白全文（與 canonical 一致｜一次錄完用）

你一定看過這種畫面：丟幾句話給 AI，程式碼嘩啦啦生出來，跑起來還會動。但真要接資料庫、做登入、要上線、要加功能——一改就炸、越改越亂。這就是 Vibe Coding 的天花板。

我是凱文大叔。寫了快二十年 Java，也教 Spring AI、出過書。我自己用 AI，三天就能做出一套能跑的企業 CRM。但要老實說：難的從來不是叫 AI 寫程式。

難的是你得知道——系統該長什麼樣、資料怎麼設計、權限怎麼擋、AI 該管什麼、不該碰什麼。這些叫 Domain Knowhow，AI 不會自動幫你想。

所以這門課，不是教你一招一式的語法。我帶你用一套 AI CRM 智慧業務助理，從零走完一條真正的產品開發路線。你會知道：登入跟權限，靠 Spring Security 跟 JWT；AI 查得到真資料、不亂掰，靠 Tool Calling 跟 RAG；金額、健康分數由 Java 算，AI 只負責摘要跟建議。重點不是背名詞——是看懂哪個技術，能換來哪一種能力。看懂了，你才指揮得動 AI。

課程全程用 Claude Code 示範，每一單元都附提示詞：先讀需求、再產程式、最後用測試驗證。走完八個單元，你手上會有一套能登入、能查客戶、能引用知識庫、能給業務建議的完整作品——直接放進履歷的那種。

現在 Hahow 募資中，早鳥優惠進行中。不用先相信我——連結點進去，這套 CRM 你現在就能線上玩玩看。告別混亂的 Vibe Coding，成為能駕馭 AI 的全端工程師。我是凱文大叔，我們課程裡見！

1. **節奏**：前 18 秒一定要快、要有痛點共鳴，留不住人後面都白搭。
2. **無出鏡**：身份段與收束用 **logo + 畫外音**，不安排講師實拍或大頭照。
3. **真實感優先**：AI CRM 畫面全部用真實操作錄影／既有截圖，不要用假 mockup。
4. **Domain Knowhow 是記憶點**：「哪個技術換哪種能力」「技術由工具算 · 文字由模型寫」字幕要清楚、可截圖。
5. **測試不搶戲**：只保留「最後用測試驗證」一句，不另開長段講 E2E。
6. **價格**：片中**不出現具體早鳥金額**；細節留給 Hahow 銷售頁。
7. **試玩 URL**：QR／字幕固定 **https://ai-crm.springai.world**；官網 springai.world 可作次要連結。
8. **數據誠實**：薪資／溢價若上字卡，沿用 land-page 出處，勿誇大。
9. **素材與字數細節**：見 `hahow宣傳內容/video_script.md`（素材總表、需現製清單、字數速查）。
